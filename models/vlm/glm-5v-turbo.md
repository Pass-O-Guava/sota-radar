## 核心能力

- **视觉编程**：原生支持视觉代码生成，能够理解截图、UI 设计稿并生成代码
- **Agent 工程优化**：专为高容量 Agent 工作流设计，支持复杂系统级任务
- **Z.ai 平台集成**：与 OpenClaw 深度集成，可通过 API 直接调用
- **2026-04-01 最新发布**：当前最新的视觉编程模型

## 许可证与商用合规

❌ **专有模型**：仅通过 Z.ai API 调用，不可本地部署，商用需购买 API 用量

## 适用场景

- 视觉编程（理解截图/设计稿生成代码）
- 复杂 Agent 工作流编排
- 需要最新模型能力的场景
